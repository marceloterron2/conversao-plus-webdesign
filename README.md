## Publicação com GitHub Pages
Após adicionar `index.html`, acesse **Settings → Pages → Build and deployment → Deploy from a branch**, escolha **main** e **/(root)**, e salve.

## Manutenção
Preservar elementos visuais existentes e a responsividade. A primeira seção usa imagem incorporada ao HTML; evitar removê-la em revisões. A segunda seção contém uma animação de pesquisa por clínica de estética próxima. Evitar pontos finais nas headlines e subheadlines.
